《我在游戏觉醒系统》EraTD v0.2.0-alpha 快速开始（视觉扩充版）
=================================================================

1. 解压本 zip 到任意可写目录（不要放进 Program Files）。
2. 双击 start-game.bat 启动游戏（不要直接双击 EraTD.exe——启动器会把
   存档/战报目录指到本文件夹内的 data\，直接运行会找不到数据根）。
3. 存档、战报与设置都写在旁边的 data\ 目录；卸载 = 删除整个文件夹。

玩什么
------
v0.2.0-alpha 在 v0.1 首发两章（E1 远古 + E2 古典）基础上整包加入视觉
扩充内容：五层 51 条过场视频（主菜单循环/时代跃迁/仪式/记忆闪回/彩蛋）、
记忆图鉴（集齐 8 段考古记忆解锁隐藏合成篇《零的真相》60 秒）、六时代
面板皮肤与加载插画、军师人格立绘、24 枚成就图标。

对左侧军令面板下一句"守住东门"试试——离线军令语法开箱即用，不需要任何
API Key。F1 打开词汇表帮助面板。

可选：视频母片合集
------------------
Release 页另附 EraTD-v0.2.0-alpha-video-masters-480p.zip（51 条视频的
480p mp4 母片，供剪辑/二开；游戏本体不需要它）。

AI 对话档（可选）
----------------
设置页填入你自己的按量计费 API Key（智谱 GLM / MiMo 已预置模板）。
注意：Coding Plan（套餐包月）密钥不能用于本游戏（服务端错误码 1315），
请使用按量计费的 API Key。游戏永久免费，AI 档费用由玩家自担（BYOK）。
