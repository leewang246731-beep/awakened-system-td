《我在游戏觉醒系统》EraTD v0.5.0-alpha 快速开始（W5 预览版）
=================================================================

1. 解压本 zip 到一个独立文件夹（建议用解压向导的"解压到 <文件夹>\"；
   不要放进 Program Files，也不要散着解压到桌面）。
2. 启动游戏：
   - Windows：双击 start-game.bat（不要直接双击 EraTD.exe——启动器会把
     存档/战报目录指到本文件夹内的 data\，直接运行会找不到数据根）。
   - Linux：终端运行 ./start-game.sh（若提示无执行权限，先执行
     chmod +x EraTD.x86_64 start-game.sh；不要直接运行 EraTD.x86_64，
     理由同 Windows）。
3. 存档、战报与设置都写在旁边的 data\ 目录；卸载 = 删除整个文件夹。

玩什么
------
v0.5.0-alpha（W5 预览版）= v0.2 视觉扩充版全部内容 + W5 新增：
- 首发两章（E1 远古 + E2 古典）可玩；
- 五层 51 条过场视频（主菜单循环/时代跃迁/仪式/记忆回放/彩蛋）、
  记忆图鉴（集齐 8 段考古记忆解锁隐藏合成篇《零的真相》60 秒）、
  六时代面板皮肤与加载插画、军师人格立绘、24 枚成就图标；
- 渲染三档（低/中/高）自动探测适配，低端集显自动降级（W5 新增）；
- JSON 模组管线（外置增改+行级报错+DSL 三族）已随开源仓库提供
  （样板模组与离线校验器见仓库 game/assets/mods/ 与 tools/ci/），
  游戏内模组入口随后续免费更新开放。

对左侧军令面板下一句"守住东门"试试——离线军令语法开箱即用，不需要任何
API Key。F1 打开词汇表帮助面板。
