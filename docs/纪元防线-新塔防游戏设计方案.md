## 1. 一句话概念

> **你的炮塔会饿，你的军师会听令。** 从石斧到星舰，每一发弹药都要自己采、自己造、自己运——传送带断流的瞬间，防线就开始挨饿。而你身边始终有一位军师：对它下达军令"弩塔×2 建于东门"，它会查战局、出方案、等你点头、合法执行。你的城还会记住你：上一时代的城墙化为遗迹，千年之后你可以亲手挖出自己当年布下的防线。

- 商店页 10 秒测试：首屏 GIF = 「传送带断流 → 炮塔减速」与「一句军令 → 方案卡 → 塔列队开建」双演示。**GIF 必须用 EA 版真实能力录屏并角标注明**（防期望落差，见 §15.4）。
- 副标语：同一条防线，从石斧守到星海。
- FAQ 口径（三条必答）：①"时代"是章节级跃迁，非局内升级树；②军师不是外挂，只能在游戏规则内行动；③**军师能听懂多自由的话？——EA 版为离线军令语法+快捷轮盘，覆盖高频军令（完全离线运行）；自然语言自由对话为 1.0 后可选云档，默认关闭、不影响平衡、需 Steam AI 内容披露（§15.5）。**

## 2. 设计支柱（裁判标准）

1. **物流即防御**：塔消耗弹药/能源，弹药靠链条供给；断链只减速不停摆，玩家能"看见"经济在哪里断了。
2. **时代即关卡**：每时代=一张大陆战役图+一套能源/物流规则+一条科技树。
3. **遗迹即传承**：旧建筑化为遗迹，可考古、可修复。
4. **军师即智脑**：玩家以**军令句（EA）→ 自然语言（1.0 后路线图）**指挥游戏内 agent；agent 的动作空间是**封闭清单+Schema 校验**，只做玩家合法能做的事，永不"发明"游戏里不存在的行为。**军师全程可选：关闭军师可全通关、可全成就、警报功能不缺失（硬验收标准，见 §18.1-R2）。**
5. **内容即模组**：全部内容 JSON 数据驱动（+ 效果原语 DSL，§16.5）；模组新塔自动进入军师可指挥范围（别名词典同步扩展）。

**独卖点**：跨时代守城 + 遗迹考古 + 大白话军师三合一。军师是相对全部竞品的净差异项。

## 3. 核心玩法循环

```
单局：采集 → 加工弹药/能源 → 建塔布防+修物流（亲手 或 军师代劳）→ 抵御波次
 → 占领关卡 → 资源入库（有上限 §8.4）→ 研究 → 选下一张图
章节（6~12 小时）：主线+奇观 → 时代跃迁（30% 资源+遗迹）→ 新时代
全局：EA《第一章组曲：从石斧到芯片》25~40h（E1~E4）；1.0 全六章 40~60h
 → 无尽模式（§10.10）/模组/联机（1.1）长尾
```

单局时长：手工关 15~40 分钟；程序关 40~90 分钟。

**失败分档**：普通关失败→残骸 30% 折扣修复（首败再 −20%）；终局关失败→只清本关存档+第 15 波检查点+一次免费演习模式；科技与全局资源池永不丢失。

## 5. 资源与生产链

- 5.1 资源分代见 §4.1+§4.3；地理稀缺逼扩张。
- 5.2 采集 2~3 级/时代，产量 ×1.8/级、能耗 ×2.7/级、单位面积产量恒定；T1 采集 0.5 件/s/坐席；链深 ≤3。
- 5.3 弹药即物流：1 件=10 发；消费者=弹药映射+能源+可选增益；效率=min(供给率)（需求≤0 恒 1）。
- 5.4 物流阶梯 0.3→0.6→10→15→20→∞；运输者=网格 A*+路径缓存+待卸队列（复用流场代价图，§16.6）。

## 6. 塔防战斗系统

- 6.1 六类塔；DPS ×2/级(±15%)、成本 ×3/级、射程 +25%/级取整、AOE −20%；跨代 ×5~8；爆发型必有代价。**玩家拥有与军师同款的拖放批量建造（军师不享有玩家没有的批量特权）。**
- 6.2 `伤害=max(d×衰减−甲,10%×d×衰减)`，先衰减后减甲，甲 clamp≥0；溅射边缘保底 40%；穿甲为弹型属性。
- 6.3 波次：数量 `max(0,min(40,基数+max(0,⌊(波−起)/间隔⌋)÷max(成长,0.1)))×数量乘子`；精英线独立 `1+⌊(波−8)/4⌋`（数量乘子恒 1）；护盾 E3 起（破盾 5s 后 20/s 再生，穿甲打断）；Boss=状态（×1.5/×1.3+技能）宿主值见 §4.1；波间隔 120s×乘子（乘子 clamp 0.5~2，实际区间 0.6~2 → 72~240s）；首波宽限 ×1.5~2（教学 ×3）；波内谷 15s。
- 6.4 流场寻路（8ms/帧、脏标记、分桶 ≤6）；建筑血量计代价（×5）迷宫合法；全封死→拆墙模式；物流交规（补给走廊/城门/权衡显性）；原型验收含"迷宫+供弹共存"。
- 6.5 英雄=守望者历代化身（E1~E5+终章本体）；技能冷却制；RTS 指挥层；可无视。
- 6.6 守城智典：卷轴=预设离线例程；与军师（§11）**共用动作注册表、预算分立**（见 §11.5 仲裁规则）。卷轴预算：每卷轴每 tick（1s）1 判定+1 动作；一塔同时只受最高优先级 1 张控制；**常驻激活上限 `6+2×时代序号` 张**。条件卡+动作卡拼装；卷轴是 JSON（模组可追加，受 DSL 约束）。

## 7. 战役与进程

- 7.1 威胁度 `clamp(0.3+0.3×邻接敌营,0.3,1.2)`；乘子映射表：

| 威胁 t | 0.3 | 0.6 | 0.9 | 1.2 |
|---|---|---|---|---|
| 数量乘子 | 0.5 | 1.0 | 1.5 | 2.0 |
| HP 乘子 | 0.50 | 0.83 | 1.17 | 1.50 |
| 间隔乘子 | 2.0 | 1.53 | 1.07 | 0.6 |

  手工主线关 6~10/大陆+程序关（胜波 `10+⌊t×10⌋`；生成器 EA 后）；登陆限相邻；主城核心区（约 15%）跨代保留为遗迹城。
- 7.2 科技树：货币=资源池（有上限）；同时至多 1 节点分期；成本 `60+max(0,Σ成本)^1.11×20×(1+0.02×已解锁数)`；三重闸门；**军师能力节点全部位于独立旁支（不前置、不阻塞任何非军师科技），提供"隐藏军师线"过滤开关**。
- 7.3 离线岁月：回合钟只在战役界面推进；进行中关卡豁免；入侵限当前时代；追帧 ≤50 回合；离线收益 4h 封顶（超出 25% 递减再封顶 8h 等效）；种子化 RNG+原子写；feature flag 可关。
- 7.4 跃迁课税见 §4.3；蓝图时代内常规获取；程序关开局套件。

## 9. 多人联机（1.1 交付，架构预留）

listen server；快照 200ms+插值；放塔=幽灵+验证广播；英雄客户端预测+和解；SDR。**军师在多人下**：动作=玩家动作过服务器审批；**军师令预算与 deny 清单在服务器侧结算**（与客户端同源单一程序集防漂移）；战斗类动作支持**进房时会话级预授权**（一次勾选，防时敏集火被人因延迟拖垮）；FocusFire 执行时对服务器验证存活的最近匹配目标自动重定向；云 prompt 数据范围限定本机玩家自有视野；军师不可操作队友建筑（deny）。

## 10. UI/UX 与新手体验

1. 谓词式提示（行为触发+持久化+可跳过+冷静期+双平台文案）。
2. 因果型提示（塔效率 <50%→检查供给线；供弹单位头顶货物图标）。
3. 脚本化首个啊哈：E1 第 2~3 波"断弹→闪红→民夫送箭→恢复"。
4. **军师首个啊哈（E2 第一关）**：**三选一预填军令**（"守东门"/"东门加弩塔"/"多囤火油矢"——三句全部保证可解析，分别对应目标级/建造级/物流级三种方案卡）→方案卡→确认→塔列队开建。**演出收尾军师主动交底**："眼下我只听得懂这些令——（打开令簿）"。演出提供"跳过，我自己建"按钮，跳过不再重弹。
5. 教学关参数化（最低威胁+10 波+首波 ×3+送资源）。
6. 暂停与变速：单机全局暂停可建造+1x/2x/3x；联机房主控速、暂停投票。
7. 建造栏按动词分类、两级灰度、逐项造价缺口、吸管复制。
8. 三层信息：静态面板+塔头状态条+物流断流可视化。
9. **军师聊天窗**：默认收起为头像气泡（有警报才弹），波中永不弹窗；方案卡只渲染已校验的结构化计划（步骤/消耗/风险红标），LLM 文本仅出现在展示区且与操作按钮视觉隔离；输入框 placeholder 永远显示一条当前合法示例句+模板自动补全（ghost text）；**快捷轮盘是通用保底输入**（桌面/主机/移动同权，非降级）；战报回放=军师决策时间轴（复用 JSONL 审计）。设置项：军师人格语气/自动允许类别（关卡级）/军师语音独立音量/**完全关闭**。
10. 无尽模式：任选时代、混编敌人、奇观带入、每 10 波词缀；**排行榜三榜分立（手动/军师辅助/全托管）**。
11. 移动端共用命令词汇；放置二次确认；军师自动降 L1+轮盘优先。
12. **分区命名标注层**：地图分区命名与动作 Schema 的位置/兵线枚举同源生成（模组新地图自动命名），区名镜头靠近浮显，令簿地名可点击定位。
13. 本地化：中/英首发（**L1 句式库双语各自交付并各自验收**）；EA 开放社区翻译。

## 11. 游戏内智能体系统——"守望者智脑"

> 逆向依据见附录 D。一句话：**军师是一个"只会用技能栏"的智能体**——军令进，封闭动作出，玩家审批，预算限量。

### 11.1 概念与三条不变式

玩家对军师下军令（打字/轮盘/预设语音按钮）→军师查战局→**方案卡**→玩家确认→合法执行→大白话汇报。

1. **动作封闭**：只能调用动作注册表里的动作（§11.3）；清单外行为在 Schema 校验层直接拒绝。
2. **权限分级**：allow/ask/deny 三级（§11.4）。
3. **预算限量**：军师令点数限量（§11.5）；侦察与问答免费。

军师不是 God 模式：只做玩家合法能做的事，且**不享有玩家没有的批量特权**（§6.1）。

### 11.2 五段管线

```
军令文本 → ① 意图路由（L1/L2/L3 三档，只做翻译）
 → ② 计划生成（多步草案+每步消耗+风险标注；复合句=意图队列拆分）
 → ③ 审批门（allow 直过 / ask 弹方案卡 / deny 拒绝并解释）
 → ④ 执行（逐条过 Schema 校验+状态校验（资源/科技/格位）→ 战场执行 → JSONL 战报）
 → ⑤ 汇报（大白话总结+消耗清单）
```

失败处理两级：**意图层失败**（没听懂）→固定话术"这句我还没学会。我听得懂的令有：……"+自动展开快捷轮盘（把听不懂变成教学触点）；**动作层失败**（听懂了做不到）→错误回喂自纠 ≤2 次，仍失败如实汇报"我做不到 X，因为 Y；我能做的是 A/B"。**方案卡原子性**：审批时对全部步骤做预算+资源原子预检，任一不足则整案拒绝（不留半执行状态）。

### 11.3 封闭动作工具清单（首发 19 个；Schema 规范学 claude-code：动词封闭、宾语开放、数量受限、危险显名、输出可回读）

| 组 | 工具 | 必填与约束 |
|---|---|---|
| 侦察（免费 allow） | `LookAround` | 空接口 |

| 建造（ask） | `BuildPlan` | `tower_id`（限已解锁）；`cells[] ≤ 4+2×时代序号`；`confirm_overwrite` 显式 true 才可拆已有建筑 |
| | `UpgradeTower` | `target_id`；`to_tier 1~4` |

| | `SetRally` | `lane`（**语言无关稳定 id**+本地化显示映射）；`stance: hold\|fall\|push` |

| | `SetTowerMode` | `target_id[] ≤6`；`mode: first\|last\|strong\|closest` |
| | `TriggerScroll` | `scroll_id`（限已装备卷轴）；**耗军师令 1 点+该卷轴 3s 内部冷却，不占常驻激活上限** |
| | `HeroOrder` | `order: move\|skill\|retreat`（限已解锁技能） |
| 管理 | `AskPlayer` | `question`+`options 2~4`（label≤8 字）；系统附"其他"；`multi_select` 必填 |
| | `ReportToPlayer` | `summary≤200 字`；`findings≤8`，`verdict: CONFIRMED\|RUMOR`；**文本长度与可疑链接过滤**（防注入滥用汇报通道） |
| | `TodoBoard` | `todos[]` 全量重写 |
| | `SpawnScout` | `lane`+`duration 钳制[15,120]s`（E1 起可用，1 点） |
| | `SetAlarm` | `after_seconds 钳制[30,600]`+`reason` 必填 |
| | `StopTask` | `task_id` 统一句柄 |

**模组联动**：动作参数空间从内容注册表自动生成（模组新塔自动进 `BuildPlan.tower_id` 枚举，`aliases[]` 别名词典同步扩展）；**动词清单不可由模组扩展**（ContentType 中该类目命名为"军师动作参数空间"）。

### 11.4 权限与安全

- **allow**：侦察/查询/规划/汇报/闹钟。
- **ask（方案卡）**：建造/升级/卖出/物流/集火/技能。卡上可勾"**本关卡内自动允许此类操作**"（关卡级会话记忆，随关卡存档持久化）。**危险位动作（SellTower/confirm_overwrite/遗迹与纪念馆拆除）永不进入自动允许**。
- **deny（永久）**：改数值、跳波、付费道具、剧情钥匙、多人动队友建筑、一切"修改状态而非执行动作"的请求。
- **PreAction 钩子**：可改写（坐标偏移+提示）或拦截。
- **WaveEnd 钩子**：汇报"守住"前规则检查漏怪路径，不满足回喂原因（≤3 轮，防死循环）。
- **防幻觉三道闸**：Schema 校验→状态校验→白名单话术。
- **提示注入防护（v2.1 新增）**：①模组字符串进入 prompt 一律标记为不可信数据+结构化分隔符；②方案卡 UI 只渲染结构化计划，LLM 文本与操作按钮隔离；③汇报/提问文本过滤长度与链接；④**计划级聚合成本上限**（单计划总消耗>当前库存 30% 强制弹卡，即使该类已自动允许）；⑤CI 增加对抗性注入语料回归（§16.12）。

### 11.5 预算与经济（v2.1 重构："一套注册表、两条预算、一个仲裁规则"）

- **军师令（点/波）**：`1+2×时代序号`（E1 序号 1=3 点但**军师令自 E2 开启**（E1 长老只问答警报，免费）；E2=5、E3=7、E4=9、E5=11、终章=13）。**周期**：波开始回复，覆盖本波战斗+后续波间建造窗口，下一次波开始时清零重置（波间是建造主时段，预算必须在位）。
- **计价**：建造类 2 点/次；战斗类 1；物流类 1；巡逻 1；侦察问答 0。
- **卷轴预算（独立）**：常驻卷轴走 §6.6 的每 tick 限速与激活上限，与军师令互不扣减（两者量纲与语义不同：常驻状态量 vs 每波流量）。
- **仲裁**：`TriggerScroll` 是唯一交点——耗军师令 1 点+卷轴 3s 冷却，不占常驻激活上限（瞬时触发）。
- **塔控制权**：军师显式指令 > 常驻卷轴；军师指令使该塔脱离卷轴控制至本波结束。
- **资源护栏**：军师单波资源支出 ≤ 当前库存 40%（防终局囤积一次性倾泻）。
- **Boss 波**：军师令回复减半，战斗类动作点数 ×2（正文规范，非仅风险表）。
- **信任度（0~100，重构防饱和/粘滞）**：正确警报 +2（**平凡必然警报不计分**）；误报 −5（**每波封顶 −5**；闹钟落空在 ±15s 系统抖动内不算误报）；采纳并守住 +3 / 采纳且失守 −3；**每波向 50 均值回归 ±1**；低于 40 = 建议频率减半（软性，不关通道）；**跨时代重置为 50**。信任只调制主动性（建议频率/闲聊密度），**永不影响功能可用性、军师令与执行质量**；整个系统可在设置中隐藏。**呈现**：不露裸数字，头像旁三档徽记（将信将疑/可托付/言听计从）+档位变化时军师自嘲台词；判定依据可在战报回放中查看。

### 11.6 交互与呈现

聊天窗（§10.9）；方案卡=计划审批 UI（玩家可改计划再确认，学 planWasEdited）；执行以"军师令旗"动画标注；战报时间轴回放；人格按时代换皮（只影响表达不影响能力）。

### 11.7 技术实现三档（共用同一动作注册表与 Schema；LLM 只是翻译官，永不直接触碰游戏状态）

| 档 | 实现 | 口径与约束 | 交付 |
|---|---|---|---|
| **L1 军令语法**（默认） | 受限文法：**12 条意图文法（含目标级模板"守住X/防住X"→方案卡）+ ≥120 句式变体 + 别名词典（随内容注册表自动扩展）+ 中文数字/量词 + 多模态指认（"点选+说这里"）+ 同音容错** | **可测验收**：原型期 ≥30 人试玩收集 ≥200 条真实命令语料，EA 出货门槛=**单意图首解率 ≥80%（中英双语各自达标）**；复合句=意图队列拆分；失败一律走澄清卡+轮盘 | EA |
| **L2 本地小模型** | 3B 指令模型（Q4_K_M，约 1.8~2.0GB+运行内存 0.5~1.5GB；备 1.5B 降级档约 1GB）做意图槽位填充（JSON mode）；llama.cpp C API+C# P/Invoke（1.0 前排 2 周集成 spike；模型选 MIT/Apache 权重；Steam Deck 兼容列入评估） | **仅战役界面/波间异步调用**（同 L3）；加载失败自动降级 L1；移动端不搭载 | 1.0 评估 |
| **L3 云 LLM**（可选，默认关） | Function calling 直连动作 Schema；每日调用预算 | 仅波间异步；**BYOK 架构裁决：玩家自配 Key 仅作官方网关计费豁免凭证，调用一律经自有网关代理转发**（白名单口径成立；Key 加密存储、可一键清除）；开启时明示数据流向 | 1.0 后 |

- 通用管线：`意图 → 动作 JSON → Schema 校验（CI 同 schema 回归）→ 状态校验 → 执行`。
- **审计**：JSONL 战报（输入/计划/每步校验/前后快照），带轮转+压缩+快照差分封顶（典型 0.1~1MB/局）；"时间轴回放"=军师决策时间轴（非游戏过程回放，口径分家）。
- **网络白名单**：单一 NetworkGateway 模块（精确主机 allowlist=自有网关域名+证书锁定）+CI 静态检查禁止模块外 HTTP+JSON 模组无网络能力。诚实边界声明：防逻辑失误与模组数据外流，不防被篡改的客户端二进制。

## 16. 技术架构

1. **语言与性能**：Godot 4；热路径一律 C#；实体非场景节点；MultiMesh 批量+整块 set_buffer。
2. **实体系统**：手写实体类+类型化分组数组+四叉树+对象池。
3. **内容注册表**：JSON；按 id 排序注册；`modid:contentid`；坏模组弹错；CI 校验；**ContentType 含 `aliases[]` 字段（军师别名词典同源扩展）**。
4. **ContentType 枚举**：……/**军师动作参数空间**（动词清单不可模组扩展）。
5. **原语 DSL 三族**：效果原语/世界操作/系统命令（§11.8 映射）。
6. **运输者寻路**：网格 A*+路径缓存+待卸队列。
7. **流场**：分桶 ≤6 场共享线程队列。
8. **渲染三档**：静态 chunk（32×32，有意偏离参照系 30×30）/低频批量/高密度整 buffer。
9. **两级存档**：战役 meta+关卡分区块。
10. **联机预留**：无头可运行；listen server；军师预算/deny 服务器侧同源结算。
11. **智能体管线**：§11.7；NetworkGateway 域名白名单（BYOK 走网关代理）；JSONL 审计（轮转/压缩/差分封顶）。
12. **工具链**：JSON 热重载；无头平衡模拟器；**军师动作回归台（≈1.5~2 人月：MVP 期 schema 夹具 18 动作×8 场景≈150 用例；EA 期状态场景+对抗性注入语料）**；**交叉引用机械回归检查（防重编号断链，v2.1 教训）**；Workshop。
13. **不做**：注解代码生成/脚本模组/完整逻辑 VM/自研引擎/自训大模型。
