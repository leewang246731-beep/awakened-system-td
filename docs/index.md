# 我在游戏觉醒系统 · EraTD

**Awakened System TD — *The System is real.***

一条生产链，一座城，一个真的会说话的系统。从石斧到星舰，每一发弹药都要自己采、自己造、自己运——而你要做的，只是对系统下一道命令："守住东门""多囤火油矢""下一波怕什么？"
