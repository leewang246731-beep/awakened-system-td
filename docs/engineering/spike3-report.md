## 1. 结论（映射可行性判定）

**判定：可行（PASS）——F.7 四步骨架（跃迁快照→锚点回放→冲突降级→密度封顶）成立，往返无丢失不变式在全部 270 次模拟跃迁（24,300 座建筑）上零违例。**

- **往返无丢失**：每建筑 either 回放（原位/移位）/降级（废墟物品）/封顶跳过，三处置计数和=建筑总数；双台账（遗迹注册表+抽象清单）恰好分割全体，无一件静默丢弃。270 次 ×2 档回放+demo+微测试全部成立（`IsNoLoss` 断言）。
- **冲突率量化**：原位回放冲突率随新大陆水+岩比例线性——`conflictRate = 0.516×(water+rock) + 0.026`（R²=1.000，水平均值）；密度维（60/90/120）几乎无效应。
- **A5 核心区口径**：让位开时核心区完好率 **98.9%** vs 区外 **81.2%**（+17.7pp）；让位关时差距坍缩至 −0.4pp——"主城核心区保留"设计有效，且效果完全归因于地形让位约束。
- **移位档（F.7 降级第一档，半径 2）**：独立噪声地形下挽回 **100%** 原位冲突（2,894/24,300 → 0）——此为上界（坑 1）。
- **推荐参数**：新大陆生成时核心区（切比雪夫半径 10）地形让位（水/岩→平原）+资源点避开让位区+移位半径 2（§6）。

## 2. 原型实现（四步骨架→代码映射）

| F.7 步骤 | spike 实现 |
|---|---|
| ① 跃迁快照 | `Spike3RelicCitySnapshot`：核心锚点+**显式 A5 核心区格子集**（切比雪夫半径 10 ∩ 已建区外扩 2，快照时一次计算、行主序排序保证字节确定性）+建筑列表（类型/等级/朝向/**相对锚点坐标**）。二进制编解码为 `ILevelLayoutSnapshot.LayoutPayload` 不透明字节（spike 自有格式；产品压缩/分块归 C-04/C-20） |
| ② 锚点回放 | `Spike3RelicReplayEngine`：新锚点+相对坐标逐格映射；格合法=界内 ∧ 地形可通行（水/岩/墙=新地形冲突）∧ 无资源点占用（`GridWorld` occupancy 层）∧ 无遗迹（单格≤1）。**价值序处理**（tier 降序→类型→id），密度封顶"按价值排序保留"由处理顺序实现 |
| ③ 冲突降级 | F.7 **移位档**：切比雪夫环 1..ShiftRadius 确定性扫描找最近空闲格；全失败→**废墟物品**（抽象清单可考古条目 `ruin|id|type|tier|cause|near`，"某处曾有一座 T3 弩塔"式），不静默丢弃。旋转/合并档为产品后续——本 spike 冲突率数字因此是完好率**下界** |
| ④ 密度封顶 | 单格≤1（回放集 `HashSet` 执法）；候选格"仅被密度占据"时判 **封顶跳过**（`abstract|...|reason=density-cap` 进抽象清单）；`GridWorld.RegisterOccupancy` 自带重叠执法作外部交叉验证（封顶正确⇒批量注册零异常） |
| 两级存档链路 | `LevelLayoutSnapshotDto` → `CampaignMetaDto` → `CampaignSaveJsonContext`（K-7 source-gen JSON）→ 回读 → payload 字节逐一相同 → 回放——真实 T-041 持久化链路上验证，非仅内存对象 |
| A5 口径 | 回放引擎只接收**解析后的 payload**（`ReplayFromPayload` 每次 decode 新对象），核心区成员判定只查持久化格子集——几何重算在结构上不可达 |

冲突类型三层：`terrain`（水/岩/墙）、`resource`（资源点占用）、`oob`（出界），降级条目带 cause 记录。

拟合与读数：

- **`conflictRate = 0.516 × (water+rock) + 0.026`，R² = 1.000**（粗糙度三水平均值，x=水+岩比例 0.09/0.18/0.27）。
- 斜率解读：≈区外建筑占比（几何 441:648 ⇒ 0.594）打 ~0.87 折扣——让位把核心区地形冲突清零后，冲突质量全部来自半径 11..16 环带；折扣含资源点密度随粗糙度微升与 E1 选址微偏置的净效应。
- 截距解读：≈资源点占用固定成本（resource 列合计 305/24,300 ≈ 1.25%，其余为曲率高阶项）。
- **密度维几乎无效应**（同粗糙度三行完好率差 ≤1.0pp）：单格冲突是逐格独立事件，不随建筑数放大——遗迹城规模不是冲突率驱动因素。
- 封顶率全表 0.0%：纯平移回放是单射，单格≤1 由构造保证；封顶只在移位竞争下触发（坑 2）。
- 移位档（半径 2）挽回：冲突 2,894/24,300（11.9%）→ **0**（挽回 100%）。
- E2 足迹阻断率（让位后、切比雪夫≤16 实测）：均值 0.1176。

## 5. A5 核心区口径验证（30 对 seed，密度 90，粗糙度 1.0；核心区=半径 10∩外扩 2，成员判定只查持久化格子集）

| 条件 | 核心区完好率 | 区外完好率 | 差距 |
|---|---|---|---|
| 地形让位 **开** | **1083/1095 = 98.9%** | 1304/1605 = 81.2% | **+17.7pp** |
| 地形让位 **关** | 884/1095 = 80.7% | 1302/1605 = 81.1% | −0.4pp（坍缩） |

- 让位约束把核心区完好率从 80.7% 抬到 98.9%（**+18.2pp**）；关掉让位后核心区与区外无差异——**"主城核心区保留"的实际效果数字完全归因于让位约束，而非核心区口径本身**。
- 核心区剩余 1.1% 损失全部来自资源点占用（让位只清地形、不清 occupancy）——推荐参数 2 由此而来。
- 样本量：核心区 1,095 座/区外 1,605 座（几何占比 40.6%/59.4%，与 441:648 格子比一致）。

## 6. 推荐参数（新大陆生成时的地形让位约束建议；交 T-074/C-20 落地）

1. **让位半径 = 核心区半径 10（切比雪夫）**：新大陆生成后、锚点回放前，主城锚点半径 10 内 Water/Rock → Plain（demo 实测清理 81 格 ≈ 2.3% 格子改写）。实测核心区完好率 98.9%（验收线 ≥95% 有裕量）。
2. **资源点布设避开让位区**（半径 10 内不刷资源点）：可把核心区残留损失 1.1% 压至 ~0——资源点是让位后核心区的唯一冲突源。
3. **移位半径 2**（F.7 移位档）：独立噪声地形下已足（挽回 100%）；真实聚簇地形落地后重标定（坑 1）。
4. **快照体积预算**：≈64 B/建筑（未压缩）⇒ 100 建筑遗迹城 <7 KB——SQLite 波界全量快照（D-11）介质无压力，无需增量编码。
5. **冲突率预算式**：`conflict ≈ 0.52×(water+rock) + 0.026`（让位开、原位回放）——新大陆若要控原位冲突 ≤8%，需水+岩 ≤~10%（或依赖移位档兜底）。

## 7. 坑

1. **独立噪声地形高估移位档收益**：GridWorld 每格独立抽取，阻断不聚簇——25 格候选窗全阻断概率 ≈ (water+rock)^25 → 0，故移位 2 环挽回 100%。真实湖/山脉聚簇下该数字必降，F.7 的旋转/合并档在那时才真正吃劲。本报告冲突率=完好率**下界**、移位收益=**上界**；产品地形生成器（C-05 演进聚簇）落地后应重跑本矩阵。
2. **封顶分支在矩阵中不可达**：纯平移是单射（两建筑不可能映射同格），单格≤1 由构造成立（全表 cap%=0）；封顶只在移位竞争/叠加快照下触发——以全水微地图单测覆盖（`Density_cap_single_cell_enforcement`：3 座同址建筑，T4 移位抢格、T3/T2 封顶跳过）。产品引入旋转/合并档后封顶真实触发面扩大，需回归。
3. **R²=1.000 是 3 点均值拟合的假象**：水平均值把 30 对 seed 的二项噪声（单次跃迁 σ≈4%@N=60）平均掉；产品回归断言应锚矩阵单元格均值（30 对聚合），不能锚单 seed 数字。
4. **让位不清 occupancy**：地形让位后核心区唯一残留冲突源=资源点（demo cause terrain=11/resource=1 的 resource 项、§5 的 1.1%）；"让位"语义在产品里应同时约束地形生成与资源点布设两层。
5. **出界（oob）维度未入矩阵**：96×96 图+锚点居中+半径 16 布局下不出现；小图/边角锚点时 oob 降级分支生效（`Out_of_bounds_home_degrades_to_ruin` 微测试覆盖，cause=oob 不抛异常不静默丢弃）。
6. **E1 选址排除不可通行格的反馈效应**：E1 城只建在可通行格（真实语义），高粗糙度下 E1 侧候选格收缩——对核心区/区外占比影响可忽略（实测 40.6% vs 几何 40.5%），但意味着矩阵的"密度"恒定为**可通行格上取样**口径。
