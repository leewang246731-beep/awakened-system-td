## 二、生产纪律执行情况

1. **prompt 结构**：每条 = 彩蛋语义提炼（源自 19-r2 触发条件与 31 号明细行，非占位文案）+ 色板 hex 写死（E-a/E-d 用全时代五色链 `#C9915C/#4E8A6E/#A8503C/#3D7EA6/#3FC1C9`；E-b 用"系统青 `#3FC1C9` vs 涂鸦暖 `#C9915C/#E07B39`"对比对；E-c 用终章三锚 `#3E55C9/#1D1B33/#BFE8F2`，即 §1.3 E1 补色回环）+ no-text 反乱码指令（E-b/E-d 追加"no numbers/no readable characters"专项）。E 层按 §1.4 破格预留允许偏离日常语法，但本批实际仅 E-b 动用破格权（涂鸦入侵 UI），其余三条仍守住层积语法本体——"彩蛋在语法内破格"比"语法外撒野"更有效。
2. **交错提交**：全程同时 ≤2 在途（与并行 B 层代理共享 API）；E-d 轮询遇 1 次 `fetch failed` 传输层抖动（与 D 层同类），30s 退避重试恢复，任务本身服务端正常完成——未重复提交、无成本影响；**未遇 429**。
3. **抽帧自审（反造假）**：每条抽 3 帧（12s 条 @2/6/10.5s、10s 条 @2/5/8.5s、8s 条 @2/4/6.5s），经 `mcp__4_5v_mcp__analyze_image` 视觉模型逐帧真跑（共 12 次审计），四判据=主体符合 brief / 色板接近 hex 锚 / 无可读文字数字水印 / 无明显 AI 痕迹。**时序感知判据**：审计 prompt 声明采样点时序（如 E-a@2s 处于横移起点只见早期时代属预期、E-d@2s 层积柱尚矮属预期），避免把叙事推进误判为缺项。重试上限 ≤2/条，实际 **0 次**。12 帧留档 `frames\`。
4. **不转码（T-152 口径）**：本批只产 mp4 母片直存 E 盘；ogv/Theora 转码、`video_frame` 步插入、E-01/E-02 图鉴封面帧抽帧（31 号 §二.3 T2 项）、彩蛋触发接线（D-11 战报尾页/零出售判定/记忆集齐投放/无尽三榜挂点）全部归 T-150/T-152。
5. **manifest（D21-4 纪律）**：每条含 prompt 全文/task_id/md5/字节数/token 实测/审查结论；成本按 token 实测入账（见下）。

## 四、口径说明与遗留

1. **E-01 明细行"玩家本关塔布局"的抽象化处理**：31 号明细写"玩家本关塔布局剪影×六时代母题塔形拼贴长卷"，实际生成做抽象化——同一防线上的时代塔形层叠（不含玩家布局数据）。玩家布局逐关个性化合成属 T-150 工程侧（视频母片作底、布局剪影程序叠加）或后续批次，本批按"收藏向时代长卷"口径交付，manifest 已记。
2. **E-b 无文字纪律的执行**：涂鸦仅限形状（塔/星/螺旋/箭头/太阳），审计 prompt 将"乱码伪文字"明确列为 FAIL 项，3 帧均确认干净——AI 生成"手写批注"极易滑向伪文字，此为该条最大风险点，首过即守住。
3. **E-c 与 A-06/A-07 的语言同族**：星门/缝隙/守望者措辞复用 A 层终章 prompt 家族（33 号），保证彩蛋预告与终章正片"同一扇门"；E1 补色回环（§1.3）在 E-c 色板上闭环。
4. **审查链路说明**：本环境 Read 工具将本地帧经临时 CDN 中转供 `analyze_image` 远程审查（1 小时级过期链接，仅审查中转，无第三方留存，与 32 号/34 号口径同性质）。
5. **入游戏挂点备忘**（T-150/T-152 输入）：E-01→零出售通关称号展示页；E-02→战报回放尾页（≥10 局解锁，挂 T-111）；E-03→记忆集齐过程投放（8 段记忆进度阈值）；E-04→无尽三榜里程碑波次（F-123）。ogv 保留 Vorbis 音轨（E 层开音频口径）。
