## 一、录屏方法学（R7 合规：真实 L1 录屏）

**引擎内建录制**：Godot 4.7.2-stable mono `--write-movie out.avi`（窗口模式，
MJPEG PCM、mjpeg_quality=0.92、60fps 电影时基）。实测（非 OBS/gdigrab）：
`3600 frames at 60 FPS (movie length: 00:01:00:00)`。

**驱动方式（录制 harness，零游戏工程改动）**：`tools/release/record/EraRecord/`
是独立 Godot 工程——把真项目 presentation 的 7 个源/资源目录以 NTFS junction
挂入（.gitignore 拦截不入库），`EraRecord.csproj` 引用 `EraCore.csproj` 并把
junction 的真源码**原样编译**（ScriptPath 与 res:// 路径一一对应，scenes/*.tscn
脚本绑定可用）。`RecordDriver.cs` 在 `_Ready` 按真 `scenes/main.tscn` 同构搭建
节点树并 `AddChild` 触发**真 Main._Ready 冒烟**（日志实证 `SMOKE_OK core=0.0.1-wave0`
`AUDIO_OK bgm=3states…`，与 CI 判据同串），随后 `_Process` 逐帧驱动与 Main 主循环
同序的渲染回路（StepFrame→SyncFrame→脏块重建→HUD 刷新）。反射仅取 internal
成员引用（SimHost/SystemPanel），不改任何被调逻辑；演示期一切状态变化走游戏
自身命令通道（军令/PlayerBuild/assign-carrier）。

**两项编排性接线（非新规则，REV 留痕）**：
1. **波起点点数重充**：表现宿主未接 C-12 逐波钩子（SimHost 仅构造时
   `BeginWave(1)`），驱动在模拟波号跨变时按 §11.4 同规则调用公开 API
   `Ledger.BeginWave(wave,false)`（与 AutopilotDirector.BeginWave 同式）——首试
   军令在波 1 中段被 `atomic-precheck:budget:2pt` 拒（日志实证，诚实保留在
   process 记录），波 2 重充后通过。
2. **提示气泡看护**：替玩家点「知道了」（Button.Pressed 真实信号路径）收新手
   提示；断链因果类提示（效率/供给字样）与饥饿观察窗内不收。

**已知边界（诚实记录）**：开发宿主 `TowerSupplyMonitor` 构造为
`warmup=int.MaxValue`（InfoLayersUi 注释同证「宽限恒 1.0」）——断链红圈/
BottleneckDetector 事件在本宿主语义下**不触发**（驱动侧遥测
`RECORD_BOTTLENECK` 全程 0 条，与效率读数 1.00 互证）。节拍①的画面证据因此
取**真实可见行为**：军令代建的新塔无供给线→弹尽哑火、敌军从其防区漏过；
有弹塔（converter 补给的 4 座旧塔）齐射击杀的对照（受击闪白/HP 变色/敌阵亡
——受击闪=真 HP 掉落事件驱动）。未伪造任何红圈/提示。

## 三、版本角标方案

ffmpeg `drawtext` 右下角 `v0.2.0-alpha`（Consolas 等宽 14~17px+半透明黑底，
GIF/MP4/截图/胶囊统一盖章；文件名不带版本点=kebab 合规，版本只在画面与
README 表格）。**像素风协调评估**：640×360 显示尺寸下小字号等宽角标与游戏
位图 UI 混排差异不可辨（T-093 位图 UI 本身含矢量渲染文字），且换版本号只改
`VERSION` 常量重跑后期、**无需重录母片**——优于引擎内烧录位图角标。字幕条
（①/② 节拍说明）同为 drawtext，中文微软雅黑。
