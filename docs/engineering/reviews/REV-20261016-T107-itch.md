- **冒烟口径（诚实分级）**：
  - Windows：**真冒烟**——导出件 `--headless --quit`，判据 `SMOKE_OK core=0.0.1-wave0 scale=1` + `EXPAND_OK verbs=16 assets_inku=52ogv+8strips images_inku=73(49aggregated+24icons)` + `CINE_V2 … image_track=resolved:49/missing:0 skin_nineslice=texture … zero_truth_playable=True` + `WEB_OK tier-table=l1-only-on-web …`（W5 新代码全在包内跑通）。
  - Linux：**结构校验降级**——本机 Windows 宿主无法执行 ELF（WSL 已启用但**无任何发行版**，实测）；判据=ELF 魔数 `\x7fELF`（EraTD.x86_64 73.8 MB）+ `data_EraTD_linuxbsd_x86_64/` 含 EraTD.dll/**libcoreclr.so/libclrjit.so/libe_sqlite3.so**（linux 自包含 .NET 运行时，dotnet publish 真打 linux-x64）+ res:// 外内容树七项就位。**运行时冒烟待首台 Linux 真机**（业主/CI 可后续补，不伪造）。
- **zip 形态（butler 通道惯例）**：**裸根**（通道根=游戏根，itch 客户端安装即玩；Windows 解压向导/7z 默认"解压到 <zip 名>/"自动成文件夹——快速开始.txt 已加提示）。两平台统一走 python zipfile 打包（`ZIP_DEFLATED`/compresslevel=9）：**ELF 与 .sh 条目 external_attr=0755，其余 0644**——Compress-Archive 不保 unix 执行位故弃用（v0.2 的 Windows 包用它，本卡起双平台统一 python 轨）。回读实测：两 zip 各 399 条目、根级 5 文件、linux zip 内 EraTD.x86_64/start-game.sh=0755、ELF 魔数在位、start-game.sh 纯 LF。
- **本轮坑（首轮实录）**：Linux mono 数据目录实名 **`data_EraTD_linuxbsd_x86_64`**（Godot 平台内部名=linuxbsd，非 linux）——首轮断言写 `linux_x86_64` 误红（导出本身成功），修正后全绿。另：首版 Windows zip 用 Compress-Archive 带顶层文件夹、Linux 用 python 裸根，两通道根布局不一致——统一为裸根重打（终版 sha256 见头部表）。

## 5. 三步上线指南（业主操作，10 分钟）

> 前提：一个邮箱。脚本/物料/文案/zip 全部就位，只差账号侧三个动作。

1. **注册 itch 账号**：https://itch.io/register （用户名即页面 URL 前缀，建议短名）。
2. **生成 API key**：登录 → 右上角用户菜单 → **Settings → API keys → Generate new key** → 复制：
   ```bash
   echo '粘贴你的key' > D:/game/config/itch_key.txt
   echo '你的用户名/awakened-system-td' > D:/game/config/itch_target.txt
   ```
3. **一键推送+装配页面**：
   ```bash
   cd /d/game
   bash tools/release/push_itch.sh        # 双通道推 zip，自动建草稿页
   ```
   然后浏览器开 itch.io → dashboard → **Edit page**：Description 粘贴 `game/assets/store/page.md` §二正文 → Cover 上传 `capsule-512-v020-alpha.png` → 媒体区按 page.md §一挂 GIF/截图/mp4 → **Pricing 选 "$0 或捐赠"（Name your own price，最低 $0）** → Kind=Downloadable game → 保存 → **Publish** → 复跑 `bash tools/release/push_itch.sh` 复核匿名 200。
4. （可选）把公开 URL 回填 `README.md`/`docs/index.md`/本 REV（page.md §四清单）。
