1. **无尽窗口车道=抽象波钟驱动**（无战场渲染——每波按活动波计划 `IntervalSeconds` 真实时间走钟，死亡终局由面板按钮触发）：入口裁定本就如此（正式入口=Begin 组装 seam，战场宿主随后续任务）；遥测三调用是真实挂接非 mock。
2. **程序关窗口车道=1 tick/帧推进**（PauseClock 接线随战场宿主面）；冒烟不打通关（600 tick 弃局行——Victory 行由 T-140 链路测试既有覆盖）。
3. **NETVIEW 冒烟的客户端命令走 PlayerBuild 建造建议**（v1 无预测的回显道实证）；军师审批全链在 NET_OK 既有判据（本批不重复）。
4. **era4 modern 行数值（tempo/root/和弦/gains）=设计侧暂拟**（31 号 §1.2 E4 身份卡无逐值行——同 T-142 era5/era6 行先例：数值真相源在表，后续实测微调走改表）。

## 九、联机存档归属裁定（设计裁定段——设计案后续版本引用）

> **裁定（T-157，2026-10-18）**：联机局（listen server 双人局）的持久化归属按产物类别分账：
>
> 1. **战报（K-8 JSONL 军令/审批/执行/汇报日志）归宿主独得**。战报是权威 Simulation 的执行流水——只有宿主持有唯一权威命令流与审批记录（48 号 §2/§4.2）；客户端镜像只是消费面，其本地无权威事实可记。宿主战报落宿主侧 D-03 根 `reports/`（回放 UI 的离线消费面照常工作）。
> 2. **成就归宿主独得**。成就是「战役进度域」的衍生（K-7/CampaignState 侧）——联机局不写任何一方的战役存档（v1 联机=独立房间局，不挂战役进度；T-139 REV §九既有口径），故"双方各得成就"无落点；若后续版本引入"联机战役共进度"，归属须随该设计重裁（本裁定不预置）。
> 3. **遥测双方各得本地账**。时长遥测（T-155）是**本地观测账**（不上传、玩家可删——设置页披露行口径）：两端各自记录本机视角的局时长（宿主记权威局、客户端记镜像追平局，source 列后续如需区分可加 `net-host`/`net-client` 值——v1 沿用 player 即可，两行各自成账互不混排）。
> 4. **依据**：①唯一权威原则（48 号 §1.2——命令同步选型的直接推论：衍生数据跟随权威面）；②观测不越权（遥测=本地行为记录，记录者即归属者）；③不预置未来设计（联机战役共进度未裁——留白待裁）。
