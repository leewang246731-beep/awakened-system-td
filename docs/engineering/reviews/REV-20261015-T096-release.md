## 2. 打包步骤实录（关键事实）

- **导出模板装载（D 盘纪律）**：Godot 4.7.2 **无** `--export-templates-path` CLI 参数（`--help` 全量输出实查，无该项；二进制 strings 亦无）。方案=官方 mono tpz（1.2 GB，github 官方 release URL）下载至 D:\game\tools\，解包为 `D:\game\tools\godot-templates\4.7.2.stable.mono\`（**目录名必须带 .mono 后缀**——首试 `4.7.2.stable` 报"未找到导出模板"，按报错路径改名后命中），再以 NTFS junction `%APPDATA%\Godot\export_templates`→`D:\game\tools\godot-templates` 让编辑器默认查找路径命中（junction=重解析点，C 盘零字节；07 §三（附）/09-env-locked 已同步登记，07 变更记录 v1.1a）。
- **GodotTools 找 dotnet 的条件（实测）**：仅设 `DOTNET_ROOT` 不够——GodotTools 的 dotnet publish 步骤按 **PATH** 搜 dotnet 可执行文件，PATH 无 dotnet 时报 "Cannot find the dotnet executable"（GodotTools.dll UTF-16 字符串佐证）+ ".NET Sdk not found. The required version is '8.0.31'"；PATH 前置 /d/dotnet 后 `dotnet_publish_project` 步骤正常（D:\dotnet SDK 8.0.425 满足版本要求）。build_v010.sh 已内化该前置。
- **mono 导出产物形态**：EraTD.exe（105 MB，PCK 内嵌）+ `data_EraTD_windows_x86_64/`（83 MB：自包含 .NET 运行时+EraTD.dll+EraCore.dll+GodotSharp.dll）；zip 压缩后 72.2 MiB。
- **res:// 外内容**：game/content 在 res:// 之外（D-02），SimHost/CinematicDirector/InfoLayersUi/AudioDirector 以 AppContext.BaseDirectory 向上探测 `game/content/...`——发布树把 game/content（全树 12 目录/570 KB）放在 exe 旁解决。
- **可写数据根（D-03 发布口径）**：DevFileStore 默认开发机根 `D:\game\game\data`（发布机不存在即抛错）；start-game.bat 以 `ERA_DATA_ROOT=%~dp0data` 注入（CS-5.2 既定通道），实测存档/战报/设置（reports/settings）均落包内 data\。
- **CC0 OGG 装载修复**：AudioDirector 原以 `FileAccess.GetFileAsBytes(res://audio/cc0/*.ogg)` 读源文件——导出包内只有 .import 重映射产物（`res://.godot/imported/*.oggvorbisstr`），源路径读空（"CC0 stinger missing"，savepack 清单佐证）；include_filter 无法强行带入已导入资源的源文件（`*.ogg` 过滤实测无效）。修复=ResourceLoader.Load（重映射感知，dev/export 两态皆通），原字节路径留作 dev 兜底。
- **导出件自退出缺陷（发布阻塞，已修复）**：首版 zip 窗口模式启动即退（前台直跑 exit_code=1）——T-092 音频验收的 `filesWritten`（res://audio/generated WAV 试听转储）在只读包体恒为 0 → AUDIO_FAIL → Quit(1)。修复（822a810）：转储判据仅编辑器运行生效（Godot `template` feature 恰标记导出运行），Persist 在导出运行短路（同时消除玩家日志里 7 处 "Could not create directory res://audio" ERROR 刷屏）；其余判据两态全部保留。**旧 zip 已从 Release 删除替换**（旧 sha256 087f704b…，新 17ed397b…；tag 同步移至修复提交）。
- **Era2TerrainAtlas.ProbePackFiles 在导出包=0/15**：探测 game/assets/era2 原始包树（不随包分发），标记行 informational，E2 图集本体已烘进纹理（atlas_tiles=9 正常）。
