## 一、架构裁决与落点（任务卡五交付面逐条）

### 1. 可选下载通道（不进主包）

- **体积裁决写实**（任务卡原文口径）：模型 Qwen2.5-3B-Instruct Q4_K_M GGUF **1.93 GB（1,929,903,264 字节）必须可选下载**；llama.cpp CPU 预编译 b11714（zip 19,662,606 字节≈18.7 MB，解压 ~66 MB）**可随主包**——主包未带时同一下载器补拉（`L2Coordinator.ResolveServerExecutable` 三级解析：设置覆盖目录→exe 旁随包 `runtime/`→数据根 `runtime/unpacked/`）。两 artifact 事实冻结于 `L2Facts`（唯一事实源，玩家可见体积文案 `ModelSizeZh` 从其推导，禁第二处措辞）。
- **sha256 校验**：模型摘要 `9c9f56a3…53f94`——本地实测（D:\models 既有 spike 文件）且与 HuggingFace LFS oid **逐字节对账一致**；运行时 zip 无服务端摘要（GitHub Releases 事实），尺寸门独扛（REV 登记，代码注释同源）。校验流程：尺寸门→流式 sha256（IncrementalHash）→失配**清盘重下恰好一次**→二次失配诚实失败（两文件皆清）。
- **断点续传**：`.part` 文件追加写；决策纯逻辑在 `L2DownloadPlan`（终稿已验→零 wire 直通/终稿未验→离线校验/半截 part→从其长度续传/外来超尺寸→清盘），策略可无网络全测。取消保留 `.part`（不为已付字节买第二次单）；传输中断同保活，跨会话续传。
- **进度显示+取消**：`L2DownloadProgress`（字节/总量/整百分比预计算）逐 chunk 回调；设置页进度条+取消按钮（CTS）。
- **落玩家数据目录**：全部经注入数据根（D-03 IFileStore.Root / 协调器 `DataRootFile`），`data/models|runtime/` 相对路径+根逃逸检查——**零盘符字面量**（R9 全绿），发布件任意盘成立。
- **dev 复用**：`settings/l2-tier.json` 的 `ModelPathOverride`/`RuntimePathOverride` 指路既有 D:\models / D:\llama-cpp（存在才生效），不重复下载。

### 2. llama.cpp server 进程管理

- **分层（任务卡原文）**：`L2RuntimeHost`（presentation/EraTD/l2/）持有 `System.Diagnostics.Process`（spawn→`/health` 探测循环 0.5s 节拍、60s 预算→**一次预热请求**（47-t129 §3.2① 消 82.5s 冷首答）→停机 Kill(entireProcessTree) 幂等）；启动参数 `L2ProviderRow.ServerArguments`（EraCore 单源：`-c 2048 -np 1 --jinja --host 127.0.0.1`——§3.2③④ 强制配套）。**EraCore 侧零进程依赖**：只放协议（OpenAI 端点/参数构造）与状态机（L2RuntimePhase/快照）——`LlmLayerGuardTests` 守卫保持绿（本轮实测通过）。
- 进程口/探针口/预热口全部注入（`ILlamaServerProcess`/`IL2HealthProbePort`/warmup 委托）——headless 冒烟与窗口真进程共用同一状态机。

### 3. LlmGateway 三档路由

- **L2=零协议改动对接**（47-t129 §2.5 实证重演为回归测试）：`L2ProviderRow.Build(port)` 合成 OpenAI 协议 provider 行（`http://127.0.0.1:{port}/v1`、temperature=0、max_tokens=200、retries=0——预算归波间队列所有，网关不得静默翻倍），经**同一 LlmGateway** 走全部既有保障（域名白名单 127.0.0.1、双超时、调用日志照记——`L2ProviderRowTests.Synthesized_row_routes_a_tool_call_through_the_real_gateway` 断言含调用日志行与 F-096 ① untrusted 包裹）。本地无密钥：常量标记 `local-lane-no-key` 入 ISecretStore（非密钥材料、llama-server 忽略 Authorization——保持网关 key 门单源，不开 L2 旁路分支）。
- **路由矩阵**（`L2RouteDecider`，纯函数）：L1 恒直通（地板档）；L2 六相位（Ready 直通；ModelMissing/RuntimeMissing/Downloading/Starting/Idle/ProcessDead→降 L1 各带独立理由）；L3 桌面直通（自身失败留在网关错误路径）、Web 平台行 L2/L3 同降 L1/WebTier（能力表驱动，`WebConstraints` 唯一来源）。
- **设置页三档选择**：`AdvisorTierRow` 下拉（L1/L2/L3）即时持久化 `settings/l2-tier.json`（`L2TierStore`，非 BYOK 字段不进保存按钮路径——同画质档位行先例）；选 L2 且工件齐→自动拉起（异步不阻塞）。**数据流向声明口径同步**：`DataFlowCompareBar.Resolve` 新增 `l2Selected` 参数——L2 行三态（未选=可选自愿下载/已选=「数据只在本机与 127.0.0.1 本地服务之间流动」/Web=平台禁用），与三档选择同拍（验收词「口径同步」）。

### 4. 波间异步

- **接入点在 K-5 意图段**（任务卡原文）：军令先走 L1（`AgentPipeline.Handle` 同步五段）；L1 澄清（Clarification/Refused）且路由矩阵裁 L2 → `WaveGapFillQueue.Enqueue`（军师面板提示「将在波间帮你再想」）。队列纯状态机（EraCore）：单飞、预算=25s（spike 热答上界 22.7s+余量，`WaveGapFillBudget` 冻结）、`OpenWindow`（波间开窗取队头）。
- **执行器**（`WaveGapL2Service`，presentation）：`OnWaveGapOpened` 派发 Task（**绝不 await——开窗调用即返**，Main 帧循环波次变迁触发）；填充 Task 走 `GatewayIntentFillPort`（LlmActionRouter→gateway→127.0.0.1）；结果经 ConcurrentQueue 手递——**队列只在主线程被碰**（PumpFrame 泵回：完成→`Complete`→五段管线 `HandleSystemAction` 重入（注册表闸全过，RL6 无旁路）→军师气泡 `[L2 波间]` 报告；超时/迟到→`AbandonInFlight`/Complete 按 id 拒收→降级横幅）。**模拟 tick 永不等待**（队列全同步方法，结构性断言 `Every_queue_operation_is_synchronous_by_construction`；宿主形态测试 `Queue_stays_responsive_while_a_fill_port_is_in_flight`）。
- **超时=放弃本轮不卡波**：deadline 由队列时钟裁决；迟到结果按 id 拒收（不会误complete下一单——id 校验是本任务发现的竞态修复点，见 §五.1）。

### 5. 失败降级 L1（验收判据）

- 三路全落 L1 且玩家可见（中性横幅先例 OffModeDowngrade——白字非风险红）：
  - **进程死**：Ready 后进程退出→`RefreshRuntimeHealth` 翻 ProcessDead→矩阵降 L1→横幅「进程已退出——已自动回退 L1」；
  - **超时**：波间预算线→放弃本轮→横幅「未在波间窗口内想好——这道令按 L1 处理，下一波间再试」；
  - **模型缺**：未下载→矩阵降 L1→横幅指向设置页下载入口。
  - 文案单源 `L2DegradationNotices`（七理由双语全覆盖测试钉死，None=无横幅）。
- 降级态军令照走 L1 澄清卡（功能零损失）；**降级回归测试=验收判据**：单元矩阵（L2RouteDeciderTests 13 用例 Theory 全相位×理由）+ G4 冒烟三路真路径（L2_OK degrade= 三项）。

## 五、诚实声明与遗留

1. **竞态修复（实现中发现）**：波间队列最初 `Complete(result)` 不校验订单 id——超时弃单后若已开下一单，迟到的旧结果会误完成新单；已改 `Complete(orderId, result)` id 校验+测试钉死（stale 完成返回 null 走降级横幅）。
2. **预存计时 flake（非本任务引入）**：`LlmGatewayTimeoutTests.Idle_gap_above_the_budget_classifies_as_idle_timeout`（T-091 既有，400ms/1500ms 真实计时）在 6612 例满载并行下偶发双跑各红 1-2 次（隔离重跑恒绿，机制=线程池饥饿下 CTS 回调延迟与流 gap 竞速）。已如实标注；若收官门禁复现将按既有 flake 处置流程登记。
3. **与 T-138 并行同文件**：settings_panel.tscn/SettingsPanelUi.cs 两文件含 T-138（TTS 预留）未提交改动（区域不重叠，构建/冒烟合并态全绿）。本任务提交时若其仍未落库，共享文件将随本任务后提交（后提交者消解先例），commit message 显式标注。
4. **遗留（下批归属）**：①L3 BYOK 军令路径面板接线复用同一 WaveGapL2Service（L3 选择的即时异步路由——矩阵已支持，填充口已可切 L3 行，接线留 T-131 联机评审后的交互定稿）；②运行时 zip 解包用 Godot ZipReader 同步循环（18.7MB 量级可接受，超大包异步化挂账）；③窗口模式波间开窗触发=波次计数变迁（敌清判据待 T-139 程序关统一战局状态机时收口）；④下载器 UI 未做最小磁盘空间预检（补拉运行时 19MB 无虞，模型 1.8GB 下载前检查挂账下批）。
