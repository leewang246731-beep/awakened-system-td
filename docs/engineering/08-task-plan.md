## 3. 任务执行纪律（强制）

**每任务全流程（缺一不可）：**

1. **分支**：`task/<C-ID>-<F-ID>-<slug>` 自 main 拉出；契约变更走独立分支+版本递增+全泳道通知。
2. **实现**：任务卡三挂齐（F-ID+C-ID+验收断言）才可开 PR；数值只经注册表 JSON（RL7）；EraCore 零 GodotSharp（守卫测试）。
3. **五级测试**：按 06 §1.6 类型映射逐级声明"已测/N-A"；DoD 14 项逐项勾选（06 §2.1）；测试命名含 F-ID（T3）。
4. **CI 全绿**：lint-scan（23 检查）→unit-logic→integration→regression-short→perf-budget 七段流水线全过。
5. **code-review 双轴**：Standards 轴=DOCUMENT_STANDARDS+CODE_STANDARDS.md；Spec 轴=任务卡验收标准原文；"测试是否真实覆盖"（DoD 7/8/13）是否决项。
6. **修复复验**：发现项分级 BLOCKER/MAJOR/MINOR；B+M 必须修复，修复 commit 后下一轮只验上轮发现项+受影响面，**直至某轮 0 BLOCKER/0 MAJOR**；MINOR 挂账 `docs/engineering/debt.md`（每组件 ≤5 条，超限升级 BLOCKER）。
7. **审查记录归档**：`docs/engineering/reviews/REV-<YYYYMMDD>-<任务ID>.md` 全轮次追加不覆盖；金样更新独立 commit（T8）；RL15 类任务记录 `rl15_checked` 字段。
8. **合入**：squash 成单 commit，message 首行含任务 ID+F-ID/C-ID；追溯矩阵回填 commit 哈希。

**并行规则：**

- 同波内**无依赖任务可并行派发子代理**（每泳道 1 子代理独立推进；泳道间只经 K-1~K-12 契约交互）。
- 串行约束（05 §3.2 S1~S9）：基线核验→v2.1 回收→任务定稿；K 契约冻结→Layer 0/1 开工；α/β 链拓扑序（C-05→{C-11,C-06}→{C-10,C-07,C-09}→C-12）；C-12 汇合后才可 C-13/C-18/C-19/C-21 全量；C-13+C-21→C-22、C-19+C-21→C-24；C-19→C-20、C-29→C-19；spike① 达标才放量 300 敌全量；文法冻结后才盲测。
- 每周一次泳道同步+契约漂移检查（契约文件 diff 为零或已走变更评审）；每波出口关口评审+速度校准。
- 评审瓶颈治理：契约/危险位/权限/预算 PR 100% 人工；常规 PR AI 评审 100%+人工抽检 20%。
