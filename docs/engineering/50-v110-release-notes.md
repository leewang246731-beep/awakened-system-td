《我在游戏觉醒系统》Awakened System TD v1.1.0 — 完全体（六时代战役+联机+程序关+无尽定版）

一条生产链，一座城，一个真的会说话的系统。从石器守到深空，一路打穿六个时代。

## 下载与运行

1. Windows：`EraTD-v1.1.0-win64.zip`；Linux：`EraTD-v1.1.0-linux64.zip`（免登录直下）
2. 解压到任意可写目录（勿放 Program Files）
3. Windows 双击 `start-game.bat`；Linux 运行 `./start-game.sh`
4. F1 词汇表帮助；`.zip.sha256` 为校验文件；可选资产 `EraTD-v1.1.0-video-masters-480p.zip`（51 条视频母片，供剪辑二开）

## 从游戏菜单里你能玩到什么

- **六时代战役 29 关（从菜单进入）**：章节分组选关（未解锁/可玩/已通关★）→ 真实关卡地图战斗（六时代美术/音乐随关切换）→ 胜利结算三星目标 → 下一关解锁；各时代终局关胜利后触发**时代跃迁**（30% 课税+文明基金+遗迹迁移）+ 过场视频；终章需先建成纪元之门，通关时按你是否开启系统播放**两版真相播片之一**
- **打赢打输都完整**：战败有败绩分档面板——检查点继续（⌊胜波×0.75⌋ 且 ≥10 波）/重开本关/退回菜单三选一
- **存档续玩**：战役中途退出自动存档，重进无损续关（军令建造经重放键保留）
- **无尽模式（开局自选）**：六个时代任选开局；词缀节奏两档可选——**滚词缀（默认，每 10 波确定滚新词缀）**或经典固定表；高波次跨时代混编敌人（3:1 主场主导渐升）；已建奇观可带入
- **程序关卡（开局自选）**：输入种子生成新关（同种子必同图）；三档难度；实测脚本局时长中位约 55 分钟（真人会更慢，游戏会自动记录你的真实用时用于校准）
- **联机（同网段/直连 IP）**：主菜单建房或加入——房主权威推进、军师命令宿主审批、断线重连不丢局；*异地联机需公网 IP 或同一路由器（NAT 穿透未做，见已知问题）*
- **军师三档**：L1 军令语法完全离线；L2 本地模型（设置页可选下载 1.9GB，下载后本地推理不联网不花钱）；L3 填你自己的按量 API Key（GLM/MiMo 预置模板）。**关闭系统可全通关**（终章有字幕版真相播片）
- **本地时长记录**：每局用时自动写在本机 data 目录（不上传不联网，设置页有说明，可删）

## 与 v1.0.0 的差异（诚实口径）

v1.0.0 的四章节内容与全部系统已就位，但**战役推进界面**（选关菜单/战败面板/演出接线）与 E5/终章两章、联机、程序关、无尽深化均为 v1.1.0 新增——v1.0.0 的"19 关战役"实际以引擎链交付，玩家菜单视角当时只能进入 E1 演示局。本版起上述表述与菜单实际能力一致。

## 已知问题

1. 联机为直连/同网段口径（NAT 穿透未做）；房主掉线=房间结束
2. 战役难度自选未实装（关卡难度固定）；战役大陆图呈现为章节列表
3. 界面双语混排（中文为主）；关卡时长预估与真人节奏有偏差（以实际为准）
4. AI 对话档（L2/L3）需自配资源：L2 可选下载模型、L3 需**按量计费** Key（套餐月费 Key 不可用，服务端错误码 1315）
5. Linux 版为结构校验出包（构建机 Windows，未做 Linux 运行时冒烟）
6. 若干深埋打磨项：力场塔/时空塔动画帧的战斗内播放、E1/E2 章末收束演出素材、基地受击伤害表现
