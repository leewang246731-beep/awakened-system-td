一条生产链，一座城，一个真的会说话的系统。从石器时代守到现代都市——对系统下一句"守住东门"离线即用；填入自己的按量 API Key，它会真的替你盯防线。**关闭系统可通关全部四章、拿全部成就——这是本作的硬验收标准，不是口号。**

## 下载与运行

1. Windows：下载 `EraTD-v1.0.0-win64.zip`（免登录，直接点击即下）；Linux：`EraTD-v1.0.0-linux64.zip`（x86_64，本版首次公开提供）
2. 解压到任意可写目录（不要放进 Program Files）
3. Windows 双击 `start-game.bat`；Linux 终端运行 `./start-game.sh`（启动器会把存档/战报目录指到包内 data/，勿直接运行二进制）
4. F1 打开词汇表帮助；各 `.zip.sha256` 为校验文件
5. 可选资产：`EraTD-v1.0.0-video-masters-480p.zip`——五层 51 条视频的 480p mp4 母片合集（供剪辑/二开，游戏本体不需要它；内容与 v0.2 母片包一致）

- **四个时代、19 关战役**（含各章最终 Boss 关）：E1 远古聚落 → E2 古典城邦（黄金三章）→ E3 工业烟囱 → E4 现代都市

- **四大奇观**：金字塔 / 大图书馆 / 世博会（+25% 吞吐）/ 互联网（雷达共享）——各有专属落成仪式视频
- **生产链塔防核心**：传送带物流、配方工坊、资源矿脉；护盾（波次盾+破盾再生+穿甲打断）、英雄单位、Boss 技能

- **无尽模式**：三榜严格分记（开局锁档）+四词缀，外推难度公式
- **觉醒系统（军师）**：19 个封闭动作、方案卡审批、信任三档徽记、TriggerScroll 触发卷轴；**L1 军令语法**（293 句式，中文盲测 98.3%）完全离线；**L2/L3 BYOK**：OpenAI/Anthropic 双协议网关，支持 GLM 与小米 MiMo（填 Key 才用，不填不联外网，调用日志玩家可见）

## AI 生成内容披露

本作使用预生成式 AI 辅助制作以下内容（**运行时不调用任何生成服务**；军师对话为可选 BYOK，只在你自配 Key 时发生）：

- **美术资产**：题图/插画/钩子/皮肤/加载图/立绘——AI 生成插画（A 档直用）；成就图标为程序合成底稿
- **视频资产**：五层 51 条过场视频——AI 生成视频（火山方舟 Seedance 2.5，480p）；《零的真相》为既有 8 段记忆的零成本重剪
- 逐条台账（模型/参数/成本）：包内 `game/assets/expand-v1/` 各 manifest，与仓库一致
- 音频：Kenney CC0 素材+程序合成（非 AI 生成）；代码：人工编写（开发过程有人机协作，见仓库提交历史）
