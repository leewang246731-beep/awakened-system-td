## 2. 关键发现详述

### 2.1 强近似项：《我在修仙界觉醒系统》（风险点 #1）

- 一款以修仙为题材的**放置类手游**，核心玩法为挂机养成 + 策略对战，目前处于**预约/待上线阶段**（未公布开服日期）。
- 渠道证据: [豌豆荚预约页](https://m.wandoujia.com/apps/8454253)（检索日期 2026-10-13）、[PP助手上线时间资讯](https://wap.pp.cn/news/1131085.html)（检索日期 2026-10-13）。
- 与本项目主名《我在游戏觉醒系统》仅一词之差（修仙界 vs 游戏），命名句式完全相同（"我在XX觉醒系统"）。**游戏品类不同（放置 vs 塔防）、平台预期不同（手游渠道 vs Steam/PC），商标法意义上的混淆可能性有限，但渠道内搜索/SEO 混淆风险真实存在。**

### 2.2 "觉醒系统"词汇的通用性（风险点 #2）

- "觉醒系统"在国内游戏中是**高频通用玩法机制术语**：游族《神权》特色玩法（[百度百科](https://baike.baidu.com/item/%E8%A7%89%E9%86%92%E7%B3%BB%E7%BB%9F/15434408)，检索日期 2026-10-13）、《策马守天关》装备觉醒、《攻城掠地》武将觉醒、《权力的游戏：凛冬将至》指挥官觉醒系统等。
- 影响: (a) 该词组作为商标**显著性弱**，单独注册第 9/41 类难度大（本项目全名"我在游戏觉醒系统"整体具备一定显著性，整体注册可行性高于词组本身）；(b) 搜索引擎结果中"觉醒系统"词条被玩法攻略与小说占据，**SEO 辨识度低**，需依赖全名传播。
- "系统流"命名在网文领域高度泛滥（《我的能力是游戏系统》等起点小说），进一步稀释辨识度，但均非游戏名冲突。

### 2.3 软著线索（风险点 #3，低）

- 网络检索发现北京钛核互动信息技术有限公司名下存在登记号 **2025SR1489670 的"觉醒系统"软件著作权**（来源: 网络检索引百度百科词条，检索日期 2026-10-13）。
- **软著 ≠ 商标**：软件著作权保护代码而非名称/商品来源，不构成游戏标题使用障碍；仅作为信息记录在案。

### 2.4 EraTD 同名占用（风险点 #4，仅历史名）

- **ERA TD**（iOS，Illumesoft 开发/发行，2012-12-12 发布；RAWG 收录 [rawg.io/games/era-td-hd](https://rawg.io/games/era-td-hd/suggestions)，检索日期 2026-10-13）。当前 App Store 美区 iTunes Search API 检索已无该应用（疑已下架）。
- **ERA-TD**（itch.io 免费开源塔防，Fellowship of the Game（巴西 ICMC-USP 学生团队），2018 年 5 月发布，**仍在架**: [fog-icmc.itch.io/eratd](https://fog-icmc.itch.io/eratd)，源码 [GitHub](https://github.com/FellowshipOfTheGame/ERA-TD)，MIT 协议；检索日期 2026-10-13）。
- Steam 无同名（最近似 Evolution TD / Ages TD，均不同名）。
- 判定: EraTD **不得作为对外发行名**使用；作为内部工程代号无碍。

### 2.5 历史名（弃用）核查结论

- **铸世防线**: 网页 + Steam 均无同名游戏（Steam 检索 0 结果，检索日期 2026-10-13）——干净。
- **纪元防线**: 无同名游戏；存在网络小说《华灵：第五纪元防线》（QQ阅读，[链接](https://on.qq.com/bqq/qbxafobpzf/p80)，检索日期 2026-10-13），跨行业、非游戏，不构成冲突。

## 4. 商标数据库检索情况与局限声明

### 4.1 中国商标网（官方）

- 入口: https://wcjs.sbj.cnipa.gov.cn/ （商标网上查询系统）
- **结果: 未能检索到。** 程序化访问返回 HTTP 406（官方系统要求浏览器会话 + 滑块验证码 + 查询人身份勾选），本代理环境无法通过。
- 替代覆盖: 通过通用网页检索间接核查，**未发现"觉醒系统"或"我在游戏觉醒系统"的商标注册公开记录**（检索日期 2026-10-13）。此为间接证据，**不等于**商标局数据库无注册/在申请记录——申请中未公开或未被引擎收录的商标无法被此方法覆盖。
- 分类背景（第 9 类计算机软件/可下载应用、第 41 类在线游戏服务）依据: [CNIPA 商品服务分类指引](https://sbj.cnipa.gov.cn/sbj/sbsq/sphfwfl)、[第41类明细](https://m.chinaweizheng.com/zscq/shangbiao/41lsb.html)（检索日期 2026-10-13）。

### 4.2 USPTO（美国）

- 入口: https://tmsearch.uspto.gov/
- **结果: 未能检索到。** 官方新检索系统为 JS 单页应用，无公开 GET API（POST 探测被拒）；第三方镜像 Justia Trademarks 返回 403（Cloudflare 防护）；WIPO Global Brand Database 为 JS SPA 无公开数据接口。
- 替代覆盖: 网页检索未发现 "Awakened System" 注册商标记录；最近似为音乐产品 "Awakened Mind System"（Dr. Jeffrey Thompson，非游戏、非在先商标证据）。
- 建议发布前由人工在 tmsearch.uspto.gov 完成一次 word mark 精确检索（10 分钟），以补齐本局限。

### 4.3 局限声明（汇总）

1. 官方商标数据库（CNIPA/USPTO/WIPO）均无法程序化直查，商标层面的结论为**间接网络证据**，非权威确权检索。
2. 平台检索覆盖: Steam（中美区）、App Store（中美区 via 公开 API）、itch.io（via 站点索引）；**未覆盖** Google Play、TapTap、B 站游戏中心、Epic 商店（Google Play/TapTap 无公开免鉴权检索接口；Epic 未执行）。
3. 搜索引擎索引存在滞后，预约期/未上线产品的收录不完整。
4. 本报告不构成法律意见；正式商标注册与确权需委托商标代理机构出具近似检索报告。

## 5. 判定结论

> **《我在游戏觉醒系统》/ Awakened System TD: 可安全使用（低-中风险，附条件）；EraTD 不得对外使用；历史名铸世防线/纪元防线无占用。**

**风险点共 4 项**（无阻断性风险，均有缓释条件）:

| # | 风险点 | 等级 | 缓释措施 |
|---|--------|------|----------|
| 1 | 强近似名《我在修仙界觉醒系统》手游在预约期（"我在XX觉醒系统"同句式） | 中 | 对外物料固定使用全名并突出"塔防/防线"品类词与英文副名，避免单独传播"我在觉醒系统"式缩略；关注其上线动态 |
| 2 | "觉醒系统"为通用玩法术语，商标显著性与 SEO 辨识度弱 | 中 | 以**全名整体**申请商标（整体显著性高于词组）；宣传主打"我在游戏觉醒系统"完整名 + Awakened System TD 双语标识 |
| 3 | 北京钛核互动持有"觉醒系统"软著（2025SR1489670） | 低 | 软著不保护名称，无需动作；记录在案 |
| 4 | EraTD 与 iOS 2012 年游戏及 itch.io 在架开源游戏同名 | 中（仅当对外启用） | EraTD 仅限内部工程代号，**禁止**用于任何对外发行/商店页/宣传物料 |

**备选名建议**（仅在风险点 1/2 被认为不可接受时启用，本次判定未触发改名）:

- 中文备选: 《我的游戏系统觉醒了》（改变句式，避开"我在XX觉醒系统"模板）、《游戏觉醒：系统防线》（品类前置，检索矩阵第 7/8 行已验证"防线"词无占用）。
- 英文保持 Awakened System TD（全平台无同名）。
