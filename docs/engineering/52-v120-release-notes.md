# v1.2.0 发布说明（存档）

《我在游戏觉醒系统》Awakened System TD **v1.2.0** —— 界面美术大修版（W10）。

> 状态：草案（T-161/T-162/T-163 面已定稿；T-164 皮肤与手感槽位待回填；
> 发版门禁数据发版时回填）。本文件随发版流水线定稿入 Release 正文。

## 这一版干了什么（一句话）

v1.1.1 游戏内容完整但界面全是文字（业主实机原话验收抓出）；v1.2.0 给游戏的
每一层界面换上了真正的美术：开机即主菜单（视频背景+牌匾+六时代色按钮）、
战役选关变章节题图+关卡卡片、战斗 HUD 全面图标化、全线时代化皮肤与手感打磨。

## 玩家可见变化（每一项都有截图证据，见 docs/screenshots/w10-*）

1. **主菜单（T-161）**：开机进主菜单——A-01 循环视频全屏背景、六塔群像 logo
   牌匾+中文大标题、六张时代主题入口卡（战役/无尽/程序生成/联机/设置/退出）、
   菜单音乐、版本角标。全部既有入口归拢于此，支持返回主菜单。
2. **选关卡片化（T-162）**：战役六章各=终关题图通栏+关卡卡片网格（每张卡=
   关卡题图缩略+关名+星级+威胁角标+锁定遮罩+终关徽记）；无尽/程序关入口
   模式卡化。
3. **战斗 HUD 图标化（T-163）**：顶部资源条=资源图标+数字；底部建造栏=塔
   图标+造价+快捷键（禁用态价红）；波次预告=敌人图标×数量；暂停/倍速按钮；
   军师面板时代皮肤+六时代立绘（同一人格随时代进化）；F1 词汇表改右缘收起
   抽屉不挡战场。
4. **皮肤与手感（T-164）**：【槽位：全线时代化面板皮肤三态/文字描边/按钮
   音效/塔射程圈/伤害飘字/待机动画——以 REV-20261020-T164 与 w10-d 截图
   为准回填】
5. **出厂包美术降级修复**：早期内部版本在玩家机上可能出现按钮无配色、背景
   无视频、卡片无图的降级态——v1.2.0 起美术资产根经三级链解析，裸包实测
   与开发机形态一致（仓库树外裸包三证留档）。

## 不变

全部游戏玩法内容同 v1.1.1（六时代战役 29 关/无尽/程序关/联机/军师三档/
TTS 预留）。Windows/Linux 双平台、免费、BYOK 不变。存档兼容 v1.1.x 战役
进度（卡片星级即读取既有进度档）。

## 与 v1.1.1 的诚实差异

- 界面层全换、玩法层零改：平衡数值/关卡数据/军师逻辑/联机协议与 v1.1.1
  逐字节同源（金样零漂移）。
- 战斗内建造栏展示当前时代塔位（e1 四塔演示位口径不变——e2+ 会话化建造
  泳道为已登记架构项，非本版承诺）。
- 菜单音乐复用战斗平静层编曲（专属菜单曲为后续项）。
