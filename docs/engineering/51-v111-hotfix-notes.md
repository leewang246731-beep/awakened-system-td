# v1.1.1 热修发布说明（存档）

《我在游戏觉醒系统》Awakened System TD **v1.1.1** —— 玩家启动闪退热修。

## 修了什么（T-158 首次实机亲测抓出，感谢业主）

1. **启动闪退（根因）**：v1.1.0 出厂包把开发自检带给了玩家——L2 车道自检在窗口模式下"车道未初始化"即无条件退出进程，玩家双击后游戏完成启动自检便自行关闭。修复：自检严格限定无头模式，玩家启动永不自检退出。
2. **数据目录错位**：玩家绕过启动器直点 EraTD.exe 时，存档/日志会落到开发者目录（DevFileStore 钉死开发根——机器特定绝对路径，登记于 07 号文）。修复：导出件无环境变量时默认落在游戏文件夹旁的 data\ 目录（绿色便携）。推荐仍用 start-game.bat 启动。

## 不变

全部游戏内容同 v1.1.0（六时代战役 29 关/无尽/程序关/联机/军师三档）。Windows/Linux 双平台。若你已下载 v1.1.0 且能通过 start-game.bat 正常启动——但本热修正是修启动问题，**请所有玩家改用 v1.1.1**。
