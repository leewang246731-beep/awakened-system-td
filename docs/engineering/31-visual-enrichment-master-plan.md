### 术语速查（第一次出现的词都在这里）

| 术语 | 大白话 |
|---|---|
| sprite | 游戏里一个一个的小图形件（塔、敌人、图标）。AI 画不准像素网格，这类**必须人工重绘**（红线） |
| 插画 | 大幅面的画（章节题图、剧情配图），不进网格，AI 可以直接用 |
| 生成倍率 | 生成 N 张挑 1 张能用的。行业经验约 5 张出 1 张（R5 §6.1） |
| manifest | 素材台账：每张图/视频记下用什么模型、什么提示词、什么种子、花了几块钱，可复现可审计（21 号 §2.2） |
| ogv | Godot 引擎唯一支持的视频格式，母片 mp4 用 ffmpeg 转码而来（18 号 C1/C2） |
| 首尾帧链 | 长视频分段生成：每段结尾截图当下一段开头，串成 30 秒以上的长片（17 号 §6） |
| 色板量化 | 把 AI 图的颜色强制收敛到本时代固定色表，保证所有素材"一个色系"（R5 §5.4/§9） |
| 母题 | 反复出现的视觉符号。本方案=同一座"守望塔"轮廓，六个时代各变一次形 |
| 补色 | 色轮上正对面的两个颜色（如橙 ↔ 蓝），放在一起最互相凸显 |

## 一、统一抽象主题（核心创意）：母题形变 × 色彩层积

### 1.1 一句话概念

**全游戏的每一张图、每一段视频，都由同一条公式生成：「一层时代主色的色域打底 × 一个正在变形的守望塔轮廓 × 一片会发光的记忆碎片」。** 玩家不需要读一个字的剧情，光靠颜色和塔的形状就能读出"文明在演进、系统在找回记忆"。

依据：R4 §3.2/C8（Gris 色彩层积 + Spore 形态演化 + Cocoon 母题重复三件套）；塔防品类"高可读性抽象"是刚需（R4 C7/C9：Thronefall 2 人团队极简剪影卖出 100 万份）。

### 1.2 六时代视觉身份卡（核心交付物之一）

每张卡五件套：**主色（hex）/ 辅助色 / 母题形状（同一守望塔轮廓的六次演化：木塔→石堡→铁塔→混凝土→能量尖塔→星门）/ 纹理语言 / 专属视觉母题**。饱和度随时代递增（E1 低饱和起步 → E5 最饱和），终章回归 E1 补色但明度压深（Gris 式"层积回归"，R4 C8）。

| 时代 | 主色（hex，建议值） | 辅助色 | 母题形状（守望塔演化） | 纹理语言 | 专属视觉母题（反复出现） |
|---|---|---|---|---|---|
| E1 远古 | 晨曦赭金 `#C9915C` | 灰岩绿 `#6B7A5A` / 篝火橙 `#E07B39` | **木望楼**：三层木构瞭望塔+茅檐 | 手斧木纹、粗石面、烟痕 | **矛尖三角**（斜插入地的一杆矛，剪影常驻画面一角） |
| E2 古典 | 青铜苍 `#4E8A6E` | 陶红 `#B3593A` / 大理石白 `#E8E2D0` | **石堡箭楼**：山墙+雉堞的石构塔楼 | 青铜浮雕、编绳纹、大理石凿面 | **山墙三角+编钟**（神庙山墙轮廓，钟声波纹） |
| E3 工业 | 铆铁赭红 `#A8503C` | 煤黑 `#2E2A28` / 蒸汽灰白 `#C9C4BC` | **铆接铁塔**：桁架格子铁塔+蒸汽管 | 铆钉、齿轮、焊缝、煤灰 | **桁架三角+齿轮**（桁架里嵌一枚转动的齿轮） |
| E4 现代 | 电网蓝 `#3D7EA6` | 混凝土灰 `#9A9A94` / 警示黄 `#E3C14F` | **混凝土雷达塔**：浇筑塔身+抛物面天线+玻璃幕墙 | 混凝土浇筑纹、电路走线、玻璃反光 | **播放键三角+雷达扇扫**（三角化播放键，扫描扇形掠过） |
| E5 未来 | 聚变青 `#3FC1C9` | 聚变紫 `#8A5FC9` / 纳米银白 `#DCE4E8` | **能量尖塔**：纳米流态尖塔+悬浮环 | 纳米流态、光流线路、全息格点 | **力场弧+六边晶格**（三角拉伸成的力场弧，六边格网） |
| 终章 深空 | 星门靛蓝 `#3E55C9`（=E1 补色） | 暗物质紫黑 `#1D1B33` / 零点白青 `#BFE8F2` | **星门**：守望塔最终形态——塔顶展开成环 | 星云层积、引力透镜弧、记忆光尘 | **星门环+裂缝**（塔"开"成了门：六时代几何母题在此闭合成圆） |

- hex 为建议值，最终以 P4 皮肤批的色板量化定稿为准（量化源=14 号 P4 六时代子色板流程）。
- 母题几何链「三角=远古矛尖→古典山墙→工业桁架→现代播放键→未来力场→深空裂缝」直接采纳 R4 §3.2 第 3 条（Cocoon 母题重复手法）：玩家从第 3 个时代起会主动预测下一形态，**预测即参与叙事**。
- 骨架纪律：系统全息面板**骨架全时代恒定不变**（设计文档 §10.2 原文），时代皮肤只换边框主色/徽记/扫描线色阶——"系统超然于时代"本身就是表达。

### 1.3 终章回环：E1 补色闭环（"记忆归源"的视觉表达）

E1 主色晨曦赭金（暖橙）与终章主色星门靛蓝（冷蓝）**互为补色**。终章最后一场演出的画面从深空靛蓝缓缓褪回 E1 的暖赭——色彩走完一整个色轮回到起点的"对面"，视觉上说出叙事的最后一句话：**零把自己拆成记忆碎片散入遗迹（§12.1 谱系），终章一切归源。** 首章第一个镜头与终章最后一个镜头互为镜像（同机位、同守望塔位、互补色），即"首尾色彩闭环=记忆归源"。实现载体=CinematicTimeline 新增 `palette_shift` 步骤（§三）。依据：R4 §3.2 第 1 条（Gris 层积回归）、R4 C8。

### 1.4 这套主题如何贯穿全部素材

| 共有语法 | 落到每件素材上 |
|---|---|
| 主题色锚 | 每张图的 prompt 首句固定写死本时代主色 hex 与色相描述（§四风格一致性第 1 层） |
| 母题轮廓 | 题图/加载图/跃迁视频里守望塔剪影必现；记忆之景里母题以"残影"形式出现 |
| 层积构成 | 画面三层：底层=时代色域（大色块）→ 中层=母题剪影 → 前层=记忆碎片高光（发光粒子/残卷纸屑） |
| 同源色板 | 全部成品过同一张时代 palette.png 量化（图/视频/sprite 三层色板同源，R5 §9 第 4 层） |
| 破格预留 | 唯一允许打破此语法的时刻=彩蛋与"系统"的 meta 演出（R4 §3.2 第 4 条：日常语法越严格，破格才越有威力） |
